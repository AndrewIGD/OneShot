# OneShot Project Optimizations and Improvements

This document summarizes all the systems, performance optimizations, ML-Agents training improvements, and environment scaling implemented across this session.

---

## 1. Stamina & Combat Balancing System

### Mechanics & Tiers
- **Discrete Multipliers**: Player speed and animation rate scale based on remaining stamina:
  - `> 0.8`: `1.2x` (Boosted)
  - `> 0.6`: `1.0x` (Normal)
  - `> 0.4`: `0.8x`
  - `> 0.2`: `0.6x`
  - `<= 0.2`: `0.4x` (Exhausted)
- **Stamina Consumption**: Attacking consumes `0.2` stamina per swing.
- **Regeneration Rules**: Stamina regeneration (`0.5/s`) completely pauses while attacking, dashing, or dodging. Regeneration resumes only after the combat action has finished.
- **Dodge Preservation**: Dodge animation rate is locked at `1.0x` normal speed regardless of current stamina tier.
- **Episode Reset**: Implemented `ResetStamina()` to restore stamina back to full (`1.0`) when an episode ends and restarts.

### Visual UI
- **Procedural Overhead Stamina Bar (`Assets/Scripts/Player/StaminaBar.cs`)**:
  - Attached directly above each player.
  - Divided into 5 distinct segment ticks matching stamina tiers.
  - Smooth color lerp transitioning from green to yellow to red.
  - Billboard-style transform rotation lock ensuring the bar remains upright when the player flips direction.

### Engine Configuration (`Assets/Scripts/FrameRateConfigurator.cs`)
- **Gameplay Mode**:
  - `Application.targetFrameRate = 60`
  - `QualitySettings.vSyncCount = 0`

  - Automatically un-caps rendering (`targetFrameRate = -1`) when communicator connects.

## 3. High-Speed ML-Agents Training Optimizations (25x Timescale / 1,500 Fixed Steps/s)

### Physics 2D Tuning
- **Collision Callbacks**: Enabled `Physics2D.reuseCollisionCallbacks = true` to eliminate garbage collection allocations generated by collision events at high step frequencies.
- **Transform Sync**: Set `Physics2D.autoSyncTransforms = false` to avoid immediate transform updates on physics operations.
- **Iteration Limits**: Tuned solver to `velocityIterations = 4` and `positionIterations = 2` for high simulation throughput without compromising collision stability.
- **Layer Collisions**: Explicitly disabled collision between `PlayerNoHit` and `PlayerNoHit`.
- **Grounded Optimization**: Bypassed redundant collision checks and raycasts in `OnCollisionStay2D` when the player is already grounded.

### Update Loop & FixedUpdate Synchronization
- Migrated player movement input, velocity application, and attack processing from `Update()` to `FixedUpdate()`.
- Set `Animator.updateMode` to `Fixed` / `AnimatePhysics` so animation states advance in lockstep with the physics simulation.

### String Hashing & GC Reduction
- Precomputed `Animator.StringToHash` integer hashes for states (`IdleHash`, `RunHash`, `AttackHash`, `DodgeHash`, etc.) inside `Player.cs` to eliminate runtime string hashing and string allocations during per-step queries.

### Audio & Visual Decoupling
- **Training Mode Detection (`Assets/Scripts/Training/TrainingModeChecker.cs`)**: Identifies whether the scene is running in headless/communicator mode.
- **Audio Suppression**: Mutes and pauses `AudioListener` (`volume = 0`, `pause = true`) during training.
- **Camera Bypass (`Assets/Scripts/CameraFollow.cs`)**: Disables camera tracking calculations and disables `Camera.main` during training.
- **Particle & Coroutine Bypass (`Assets/Scripts/Hitbox.cs`)**: Skips particle instantiations and hit-stop coroutines during training mode to prevent memory fragmentation.

## 4. ML-Agents Training Enhancements

### Observation Vector (`Assets/Scripts/Player/StickAgent.cs` & `RunningStickAgent.cs`)
- Added current stamina value to vector observations (`Observations[19] = Player.Stamina`), allowing the reinforcement learning model to learn stamina management.

### Reward Normalization
- Normalized step rewards using `Time.fixedDeltaTime` so reward accumulation remains constant across different physics timesteps and simulation speeds.

### Decision Requester Tuning
- Configured `DecisionPeriod = 2` with `TakeActionsBetweenDecisions = true`, cutting neural network inference requests by 50% while maintaining physics responsiveness.

### Episode Lifecycle
- Hooked `Player.ResetStamina()` into `OnEpisodeBegin()` to ensure fresh agent starts across all training iterations.
